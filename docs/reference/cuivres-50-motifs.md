# 50 motifs pour sections de cuivres et saxophones

Chaque motif forme une boucle d’une ou deux mesures. Les 50 motifs sont des compositions originales pour le travail de l’arrangement. Ils prolongent les exercices et les références d’écoute du [guide des sections de cuivres](https://chatgpt.com/library?file_id=libfile_1d9cbb9e736c8191a6324e718e1ee9d7&account_id=personal).

## Lire les grilles

- **Mesure**. Toutes les grilles sont en 4/4. Une attaque comme `2.3&` signifie « mesure 2, contretemps du temps 3 ». En jeu droit, les subdivisions d’un temps sont `1, 1e, 1&, 1a` à intervalles de double croche. En swing, le `&` se place aux deux tiers du temps.
- **Hauteur réelle**. Do4 = MIDI 60. Les numéros MIDI entre parenthèses font foi si ton appareil affiche une autre octave. Les partitions pour instruments transpositeurs se déduisent ensuite de ces hauteurs entendues.
- **Correspondance**. La première attaque, la première note, la première durée, la première vélocité et la première articulation forment un événement. On lit ensuite les colonnes dans le même ordre. Les durées sont exprimées en temps. Une durée de ¼ vaut une double croche, ½ une croche et 1 une noire. Les espaces sont des silences.
- **Articulations**. **D** = détaché léger, **A** = attaque accentuée, **M** = note portée avec attaque nette, **T** = tenue ou phrasé lié lorsque les notes se suivent. Les durées correspondent à la saisie MIDI. Si le son ajoute du relâchement, ajuste son enveloppe pour conserver les silences.
- **Dynamique**. Les vélocités sont des valeurs de programmation. Sur un son orchestral prévu pour cela, dessine l’intensité des tenues avec le contrôleur de dynamique du patch. Le registre correspond à la note la plus basse et à la note la plus haute écrites pour chaque instrument dans le motif.
- **Harmonie**. Les accords sont un support pour une guitare, un clavier ou une basse ajoutés. La section peut ne jouer qu’une partie de l’accord.

Les tempos sont des réglages de départ. Pour un premier essai sur le Fantom-06 ou dans Ableton, enchaîne **11** pour les accents funk, **21** pour le mambo, puis **38** pour comparer les attaques courtes avec les tenues orchestrales.

## Enchaîner les motifs

- **Funk en quatre mesures**. Joue **11** deux fois, puis **15**. Le passage de Fa9 à Si♭9 arrive dans la dernière mesure.
- **Salsa en quatre mesures**. Joue **22** puis **25**. Les deux mesures de chaque motif suivent la même orientation de clave. La dernière tenue peut déboucher sur le retour du chant.
- **Cinématique en quatre mesures**. Joue **36**, puis **39**, puis **38**. La dernière mesure ouvre l’harmonie vers Si♭ majeur et place la trompette au sommet.

**Confiance élevée** sur la cohérence des grilles. Les articulations et niveaux d’expression dépendront du son utilisé.
