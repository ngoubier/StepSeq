# Prosodie et rythme

Compter les syllabes chantées et exposer les choix de prononciation. Pour un octosyllabe, viser huit syllabes ; pour un alexandrin classique, douze avec césure usuelle 6+6, sans en faire une obligation pour toute chanson. Pour le vers classique, traiter le e caduc suivant sa position (notamment devant voyelle et en fin de vers) ; pour le chant, préciser les e effectivement prononcés ou élidés. Ne pas compter par simple découpage orthographique automatique. Si deux scansions plausibles changent le placement, présenter le choix ou poser une question ciblée.

Autoriser des propositions de réécriture signalées. Faire correspondre le tableau final à la version effectivement utilisée, en conservant visible l’original si modifié.

# Unités

Utiliser la noire comme unité de calcul indépendante du dénominateur de la mesure :

| Valeur | Durée en noires |
|---|---|
| Ronde | 4 |
| Blanche | 2 |
| Noire | 1 |
| Croche | 1/2 |
| Double croche | 1/4 |
| Triple croche | 1/8 |
| Noire pointée / blanche pointée | 3/2 / 3 |
| Croche de triolet / noire de triolet | 1/3 / 2/3 |

Appliquer les mêmes durées aux silences correspondants. Employer soupir pour une noire de silence, demi-soupir pour une croche, demi-pause pour une blanche. Distinguer la pause utilisée comme silence de mesure entière des autres valeurs.

En 4/4, compter quatre noires ; en 3/4, trois ; en 6/8, trois noires de durée totale mais normalement deux pulsations de noire pointée. Expliquer l’unité de BPM et convertir en BPM à la noire pour le MIDI si nécessaire.

# Exemple de huit syllabes, deux mesures, répartition 3+5

Traiter les identifiants S1 à S8 comme huit syllabes, sans inventer de mots. Sur deux mesures 4/4 :

| Mesure | Événements successifs | Total | Attaques |
|---|---|---|---|
| 1 | S1 blanche, soupir, S2 croche, S3 croche | 2+1+1/2+1/2=4 | 3 |
| 2 | S4 noire, S5 croche, S6 croche, S7 noire, S8 noire | 1+1/2+1/2+1+1=4 | 5 |

Autre rythme pour trois attaques : noire pointée + croche + blanche = 3/2+1/2+2=4. Pour cinq attaques avec respiration : soupir + deux noires + deux doubles croches + une croche = 1+1+1+1/4+1/4+1/2=4.

Ne pas assimiler nombre d’attaques et nombre de hauteurs distinctes. Pour une tenue entre deux mesures, compter une seule attaque ; pour deux notes répétées, compter deux attaques. Pour des triolets, vérifier le groupe et la somme exacte. Ne pas remplir une fin de phrase par des notes superflues : prolonger ou laisser respirer.
