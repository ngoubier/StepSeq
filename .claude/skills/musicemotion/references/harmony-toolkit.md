# Boîte à outils : harmonie, mélodie et émotion

## 1. Fondations

- **Tonalité** : centre de gravité ; degrés I, ii, iii, IV, V, vi, vii° en majeur ; i, ii°, ♭III, iv, v/V, ♭VI, ♭VII en mineur selon la forme.
- **Fonctions** : stabilité (tonique), départ/mouvement (pré-dominante), tension (dominante), mais leur perception varie selon le style.
- **Cadences** : V–I (authentique), IV–I (plagale), V–vi (évitée en majeur), demi-cadence sur V ; remarquer qu'une loop pop n'emploie pas nécessairement les fonctions classiques.
- **Rythme harmonique** : fréquence de changement des accords. Ralentir peut élargir le sentiment d'espace ; accélérer peut créer de l'urgence.

## 2. Extensions et suspensions

- `C` = C E G ; `Cm` = C E♭ G.
- `Cmaj7` = C E G B ; `C7` = C E G B♭ ; `Cm7` = C E♭ G B♭.
- `Cadd9` = C E G D ; `Csus2` = C D G ; `Csus4` = C F G.
- `Cdim` = C E♭ G♭ ; `Caug` = C E G♯.

Une extension n'a pas d'émotion intrinsèque ; sa place, son registre et son orchestration comptent.

## 3. Emprunts modaux et modalité

- Emprunter `iv` mineur en majeur : en C majeur, `Fm → C`, pour une couleur inattendue.
- Emprunter `♭VI` en majeur : en C majeur, `A♭` avant `G` ou `C`.
- **Dorien** : mineur avec sixte majeure (D dorien : D E F G A B C). Exemple `Dm7 → G`.
- **Phrygien** : mineur avec seconde mineure (E phrygien : E F G A B C D) ; relation E–F distinctive.
- **Lydien** : majeur avec quarte augmentée (C lydien : C D E F♯ G A B).
- **Mixolydien** : majeur avec septième mineure (G mixolydien : G A B C D E F).

Préciser le centre et les altérations pertinentes avant de qualifier une progression de « modale ».

## 4. Tension et résolution

1. Établir la stabilité (tonique ou motif reconnaissable).
2. Introduire une attente : dominante, mouvement chromatique, note étrangère, suspension, silence ou montée de densité.
3. Choisir de satisfaire l'attente, de la différer ou de la détourner.
4. Observer l'émotion perçue, sans attribuer une signification universelle.

Exemple en La mineur : `Am | Dm | E7 | Am`. `E7 = E G♯ B D` contient `G♯`, sensible de A mineur harmonique, créant une direction forte vers A.

## 5. Conduite des voix

Chercher les notes communes et de petits mouvements entre les accords lorsque l'intention est la fluidité. Choisir délibérément des sauts, changements de registre et densités pour un contraste marqué.

Exemple : `Am = A3 C4 E4` vers `Fmaj7 = A3 C4 E4 F4` (voicing sans fondamentale grave ; fournir `F2` à la basse). Le noyau A–C–E est conservé pendant que la basse change.

## 6. Mélodie émotionnelle

- Motif de 2–5 notes ; répétition puis variation.
- Notes d'accord sur les temps structurels, tensions/passing tones volontairement placées.
- Contour : montée pour intensifier possible ; descente pour relâcher possible, jamais automatique.
- Longueur des notes et silence aussi importants que les intervalles.
- Point culminant préparé dans l'architecture globale plutôt qu'un sommet à chaque mesure.

## 7. Comparaison A/B (un seul changement)

| Variable | A | B |
|---|---|---|
| Cadence | E7 → Am | E7 → F |
| Couleur | C | Cmaj7 |
| Bassline | fondamentales | pédale A |
| Mélodie | descending | ascending |
| Voicing | serré | ouvert |
| Rythme | longues tenues | syncopes |

Vérifier que toutes les autres variables sont gardées aussi constantes que possible.
